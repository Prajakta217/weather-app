# 🌦️ Weather App

A simple and responsive Weather App that allows users to check current weather information for different cities.

## ✨ Features

- Search for weather by city name.
- Display current temperature and weather conditions.
- Show humidity and wind speed.
- Display weather information using weather icons.
- Responsive design for desktop and mobile devices.
- Handle invalid city names and errors.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/weather-app.git
   ```

2. Open the project folder:

   ```bash
   cd weather-app
   ```

3. Open `index.html` in your browser.

## 🌐 API

This project uses the [Open-Meteo API](https://open-meteo.com/) to retrieve weather forecast data. It also uses the Open-Meteo Geocoding API to search for cities.
